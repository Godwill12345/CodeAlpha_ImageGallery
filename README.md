📌 About the Project

The goal of this project was to design and develop a responsive image gallery with an interactive user experience.

The project includes a grid-based image layout, hover effects, smooth transitions, navigation controls, and a lightbox view that allows users to view images in a larger format.

I chose anime images for the gallery because I wanted to combine my interest in anime with my interest in frontend development and make the project more personal and enjoyable to build.

⚙️ How It Works

The gallery displays multiple images in a responsive layout.

When a user selects an image, JavaScript opens a lightbox view, allowing the image to be displayed in a larger format.

Inside the lightbox, users can:

- Move to the previous image using the Previous button.
- Move to the next image using the Next button.
- Close the lightbox and return to the gallery.

CSS hover effects and transitions are also used to make interactions feel smoother and more visually engaging.

📱 Responsive Design

The gallery is designed to adapt to different screen sizes.

CSS media queries are used to adjust the gallery layout and image sizing depending on the available screen width, allowing the project to work across:

- 💻 Desktop screens
- 💻 Laptops
- 📱 Tablets
- 📱 Mobile devices
